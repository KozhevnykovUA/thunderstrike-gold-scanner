# Thunderstrike Gold Scanner

Automated market scanner and profession optimizer for WoW TBC Anniversary, Thunderstrike EU Alliance.

## Market scope

- Region: EU
- Realm: Thunderstrike
- Realm ID: 6409
- Faction: Alliance
- Auction House ID: 2

## Goals

- collect auction-house prices automatically
- estimate effective buy prices instead of relying only on lowest buyout
- optimize profession leveling routes by expected gold cost per skill-up
- compare sell vs disenchant value
- rank profitable crafts using margin and liquidity
- start with Enchanting, Cooking, and Blacksmithing
